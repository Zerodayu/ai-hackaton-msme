# Project for Ai Hackaton

### Requirements
- [Bun](https://bun.com/)

### Clone Project
```bash
git clone https://github.com/Zerodayu/ai-hackaton-msme.git
```

### Install Dependencies
```bash
cd ai-hackaton-msme
```
```bash
bun i
```

### Setup Environments
- [Backend Repo](https://github.com/SerenicuS/ai-hackathon-msme-ai)
> find the `env.sample` file the create `.env` file on root directory and paste your database url(NeonDb)

### Run Dev Server
```bash
bun dev
```
